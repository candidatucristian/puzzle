# The Captain's Cabin: the flat chart (archived 2026-11-13)

`map.webp` was what the envelope in the bottle opened to until 2026-11-13: a
flat 2560×1600 chart with a dark border, the bearings in Georgia italic, an
island and a compass rose (made by `art/blender/captains_bottle_publish.mjs`).
The user wanted every puzzle letter to be the Rotor's letter, identical, so it
was replaced by `art/blender/puzzle_letter.py --letter compass`
(`public/assets/images/Compass/native-bottle-v1/letter.webp`).
