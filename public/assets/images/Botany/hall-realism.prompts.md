# Botany hall photographic repaint

Generated with the built-in imagegen tool. The current hall's projection, walls, six doors and their numbers, gate, stairs, ceiling lantern, chandelier, clock and furniture anchors are retained. This is surface and individual prop artwork rather than a full-screen replacement room.

The theme is more strongly botanical: photographed mature palm, lush Boston fern, flowering hydrangea in a stone urn, hanging fern baskets, fine ivy shoots, real fallen leaves, museum herbarium specimens and actual pots/watering can/seed packet. Plants occupy the existing furniture locations, with the palm more mature and fuller. Ivy ends above door heads where necessary. Existing chains support the photographed hanging baskets. The crop boundaries include the complete pot bases; the foliage image's actual column extents are used so the hanging fern is not clipped to an imagined equal-width cell.

Wallpaper, oak wainscot, doors, floorboards, moss-green carpet, ceiling plaster, lantern glass, stair treads, clock case and table/trunk receive photographic materials. The clock keeps its correct face, weights, glass and animated pendulum. Door swinging reuses the same photographed door material. Flame glows, dust, gate and chandelier behavior remain native. The previous Physics hall is unchanged by these two hall repaints.

Reused sconce photograph: public/assets/images/Physics/observatory-fixtures.png.

No tests, build or game preview were run; the user requested visual approval first.
