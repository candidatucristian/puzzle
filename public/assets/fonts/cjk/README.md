# Simplified Chinese fonts

Noto Sans SC and Noto Serif SC are bundled locally for the Chinese interface,
canvas documents and puzzle labels. The original variable TrueType binaries
are unmodified. They load when Chinese glyphs are needed, without a runtime CDN.

Downloaded from the official Google Fonts repository on 2026-11-08:

- [Noto Sans SC source](https://github.com/google/fonts/tree/main/ofl/notosanssc)
- [Noto Serif SC source](https://github.com/google/fonts/tree/main/ofl/notoserifsc)

The full SIL Open Font License 1.1 texts and upstream copyright notices are in
`NotoSansSC-OFL.txt` and `NotoSerifSC-OFL.txt`, beside the font files.
Source download URLs, sizes and SHA-256 digests are recorded in `sources.json`.
